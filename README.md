# Mario Esteban Cárdenas Vélez

Personal academic website: https://marioc612.github.io/

PhD researcher in biogeochemistry at the Max Planck Institute for Biogeochemistry and Wageningen University. Research interests include regional top-down CO2 estimation, tropical South America and nighttime atmospheric inversions.

## Updating the website

Edit `index.html` to update the biography, research descriptions and links. The page includes its own responsive styles and does not require a build tool. GitHub Pages publishes the site from the main branch.
